RS01 tools

Set the clock of a Contec RS01 sleep apnea screen meter, and turn its recordings into files OSCAR can import. Everything runs in your browser; nothing is sent anywhere.

Set the clock

Switch the RS01 on, plug it into this computer with a data USB cable, then press the button. The RS01 gets the time shown below. Needs Chrome or Edge on a computer; the first time, pick “Sleep apnea screen meter” when the browser asks.

Convert nights for OSCAR

With the RS01 plugged in, its card shows up as a disk. Drop a night’s folder (the .HD file and its .SEG files), or the whole card. Works in any recent browser.

Drop the night’s folder here

Several nights at once work too.

OSCAR file resolution

If OSCAR rejects a 1 s file, try 4 s, the O2Ring’s own rhythm. The spreadsheet file always keeps every second.

Importing into OSCAR

  1. Open the downloaded .zip archive (double-click on a Mac).
  2. In OSCAR, choose File › Import › Viatom/Wellue.
  3. Select the file named after the date and time, with no extension (for example 20261102052830). The .csv file is only for a spreadsheet.
